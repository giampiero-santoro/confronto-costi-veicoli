# Confronto costi veicoli

Applicazione web per confrontare consumi e costi di percorrenza tra veicoli a benzina, diesel, GPL, metano, ibridi ed elettrici.

## Funzioni

- Confronto di 2 o più veicoli, con aggiunta e rimozione
- Consumo in l/100 km, km/l, kg/100 km, km/kg, kWh/100 km o km/kWh, con conversione automatica nell'altra unità
- Distanza singola oppure km giornalieri, settimanali, mensili o annui
- Per i veicoli elettrici: capacità della batteria e autonomia stimata in base al consumo
- Consumo totale, spesa totale e costo al km
- Veicolo più economico e più costoso in evidenza
- Differenze di spesa tra ogni coppia di veicoli, anche per giorno, settimana, mese e anno
- Proiezione di costi e consumi per giorno, settimana, mese e anno
- Interfaccia con [Bulma](https://bulma.io) (inclusa nel file, funziona anche offline) e palette grafite/rosso/ambra
- Tema chiaro e scuro automatico

## Uso

È un unico file HTML senza dipendenze: apri `index.html` nel browser.

## Pubblicazione con GitHub Pages

1. Crea un nuovo repository su GitHub.
2. Carica `index.html` e `README.md` nella radice del repository.
3. Vai in **Settings → Pages**.
4. In **Build and deployment** scegli **Deploy from a branch**, branch `main`, cartella `/ (root)`, poi **Save**.
5. Dopo qualche minuto il sito sarà online su `https://TUO-UTENTE.github.io/NOME-REPOSITORY/`.
